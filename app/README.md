# The App to Query, Retrieve, and Update Database

This folder contains the source code of the (minimal) application that allows user interaction with the database.

# App 

My app is a very basic one. You can update the checkout total for a certain patron. The app showcases a few things: 
ID, Patron Type, Checkouts, Library, Month, and Registration. Read the directions to check it out! Or look at the photo. 
Do what you want! I can't boss you.
